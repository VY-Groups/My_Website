## How to Add Files

1. Place your PDF files in this `resources/` folder
2. Update the materials data in `/api/data/materials.js` with:
   - File title
   - Category
   - Description
   - File size (optional)
   - Download link: `/downloads/resources/filename.pdf`

## File Guidelines

- **Recommended Format**: PDF
- **Max File Size**: 10 MB (recommended)
- **Naming Convention**: Use lowercase, hyphens, no spaces
  - ✅ Good: `linux-essentials.pdf`
  - ❌ Bad: `Linux Essentials .pdf`
